# Namaste, I'm Ragen Maharjan 👋

### Certified Computer Engineer | Senior Flutter Developer | Mobile Lead Developer at InfraByte

I'm a certified computer engineer from Kathmandu, Nepal, and I've been building software since 2018. I started
with .NET desktop apps and PHP websites, moved into Flutter in 2020, and today I lead mobile development at
[InfraByte](https://app.infrabyte.com.au/), an operations platform for Australian car removal, towing and auto
recycling businesses. I've shipped apps to the App Store and Google Play, built the backends and dashboards
behind them, and taken them through release and maintenance.

- 🔭 Currently building the InfraByte mobile app and web dashboard: job booking, driver dispatch, real-time tracking, reporting and a VIN decoder.
- 🚀 Published apps on the App Store and Google Play: InfraByte, E-Sell Today and Shram Sanskriti.
- 🌱 Exploring scalable software architecture and backend development.
- 🎓 Studying for an MSc in IT Management at LBEF, with a [published paper](https://doi.org/10.67825/lrjstm.2026.8015668) on AI in Nepal's e-commerce sector.
- 💬 Ask me about Flutter, mobile releases and backend development.
- 📍 Kathmandu, Nepal
